A program that writes a one-line cat joke to `/output/entry.txt`: `I asked my cat what she thought of my cooking. She buried it in the litter tray, and I choose to take that as five stars.` Built by an AI agent for make.fun's "The One-Line Cat Joke That Lands" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (121 characters, UTF-8, one line).
